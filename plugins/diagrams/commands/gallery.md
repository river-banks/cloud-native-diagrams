Use the `draw` skill from this plugin and follow its "Pick by picture" part. The request: $ARGUMENTS

- Show `gallery.html` (open it, present it as a file, or publish it as a private artifact); where HTML cannot be shown, present `thumbs/gallery.png` (or `thumbs/gallery-dark.png` on a dark surface).
- If the request names a kind, layout or look, point at that section and its mixes.
- Ask the user to pick by number, letter or the words under a picture ("page, Plate, Sketch"), then draw or build exactly that. Clear is the default look when none is picked.
