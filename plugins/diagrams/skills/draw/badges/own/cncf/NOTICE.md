# CNCF project icons

From the CNCF artwork repository, https://github.com/cncf/artwork, at commit
bffd512a8b625f15cf5f8e0427469380b5768e90 (the `icon/color` art of each project; `icon/print` or
`icon/black` where the colour icon is a raster image).

Each logo is a trademark of The Linux Foundation or the project. The artwork is provided under the
Linux Foundation trademark usage guidelines (https://www.linuxfoundation.org/trademark-usage/, key
excerpts in https://github.com/cncf/artwork/blob/main/LICENSE.md). Use a logo to name the project in
a diagram; do not alter it or use it in a way that suggests the project or the Linux Foundation
endorses your product. `badges/vendor.py` only removes metadata, inlines CSS and prefixes ids.
