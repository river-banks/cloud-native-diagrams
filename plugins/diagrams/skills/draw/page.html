Every style at a glance

Badge library

Logos for the products we draw most. AWS services use the official AWS Architecture Icons, unchanged. Everything else uses the Simple Icons glyph in the brand's own colour. Each style picks one treatment; you can preview them all here.

Where the styles come from

    To add a style, an example or a badge, see diagrams/README.md in the cloud-native-diagrams repo: one JSON file or one line, then python3 build.py.

    Badges: AWS Architecture Icons from the AWS asset package (AWS lets you use them in architecture diagrams). Other logos: Simple Icons glyph data (CC0); each logo is still its owner's trademark, so use it only to name the product. Fonts: Excalifont (OFL), IBM Plex, Archivo, Overpass, Hanken Grotesk, JetBrains Mono (OFL).
